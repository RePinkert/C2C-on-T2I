# 多样性题材 Starter（补充 prompt 库）

> 供扩写图生文评测 prompt 时参考。挑题材、组合维度即可；每类都在"同一题材、不同画面"上展开，
> 避免同质化。中英双语，选题时语言（含中英混合）、复杂度、风格媒介、场景主体、镜头构图都应交叉覆盖。

## A. 题材池（选题时尽量不重复主体+场景组合）

- 日常现场：夜市摊贩、早读课桌、地铁末班、修自行车的铺子、菜市场鱼摊、老理发店、公交站、候车的舞者
- 自然：雨后梯田、盐湖结晶、山口云海、雪后渔港、沙漠星空、苔原花海、林中兽眼、秋林落叶
- 城市/建筑：老居民楼外墙晾衣、天际线夜景、图书馆穹顶、水乡石桥、废弃工厂改造剧场、筒子楼走廊
- 静物/材质：做旧皮箱、铜壶茶具、琉璃器、陶土粗陶、生锈工具、蝉翼薄纱、玻璃器皿逆光
- 人物瞬间：老人下棋、母亲织毛衣、雨中撑伞的学生、候车的舞蹈演员、铁匠打铁、卖花老人
- 动物：深山夜行兽眼、海鸥盘旋、猫咪蜷在键盘、候鸟齐飞、柴犬树下、鱼缸金鱼
- 抽象情绪（必须落到具体场景锚点，不要写"feeling of X"）：孤独、紧张前一刻、怀旧、宁静、荒诞、史诗
- 风格化/设计：旅行海报、电影海报、信息图、建筑渲染、儿童绘本、像素游戏、水墨、工笔、浮世绘、
  Concept art、包装设计、版画、连续线稿
- 中文语境专属：庙会、早市、老巷弄、胡同八卦、年夜饭、春节集市、园林一角、工笔重彩、敦煌飞天

## B. 维度（横向可交叉）

1. **语言**：中文 / 英文 / 中英混合（如"汉字霓虹 sign"）——中文是 C2C 退化重灾区，保持 ≥ 1/3
2. **复杂度**：短句单体（~8–15 词）→ 多物体空间关系 → 抽象情绪+场景锚点 → 长描述混合风格（~30–60 词）
3. **媒介/风格**：写实摄影 / 油画 / 水彩 / 国画 / 工笔 / 像素 / 矢量平涂 / 概念设定 / 儿童绘本 / 海报
4. **镜头与构图**：微距 / 航拍 / 低角度 / 浅景深 / 剪影 / 居中对称 / 三分法 / 前景框架 / 立轴纵构图
5. **光照氛围**：黄金时刻 / 雨后 / 雾 / 烛光 / 霓虹 / 逆光剪影 / 夜景长曝
6. **主体关系**：单人 / 多物体空间 / 人与环境互动 / 纯静物

## C. 变体（deviation）怎么生成（以 7 条基准扩 21 / 28 条）

对每条基准，分别产出**只动一个维度**的变体，保证 21 条覆盖不同语言/媒介/复杂度：

1. **中文直译版**：英文基准忠实翻译为中文（保留所有细节与"禁文字"尾巴）；英文基准的中文版看语言维度影响
2. **媒介/风格切换版**：换成水彩 / 素描 / 矢量 / 水墨 / 工笔 / 儿童绘本 / 油画等完全不同的绘画语言
3. **短句压缩版**（raw 臂简短对照组）：~8–12 词，只保留主体+场景+一个关键约束，如 `雨后梯田，墨色山水，一顶斗笠`
4. **画面参数版**：只换镜头/光照/构图（低角度→俯瞰、昼→夜、顺光→逆光……），其余不变

每个基准建议产出：中文直译 1 条 + 媒介切换 1 条 + 短句 1 条（= 3 变体/基准，7 基准 → 28 条）。

## D. 质量红线（写进每条 prompt）

- 含"禁止文字/watermark/logo"尾巴（避免 T2I 模型往画面上印字，干扰 CLIP 分与盲评）：
  `Absolutely no text, no typography, no letters, no words, no numbers, no logos, no watermark, no captions, pure imagery only.`
- 不要自带分辨率/步数/cfg/LoRA 等渲染指令——渲染参数由生成管线固定（1024²，固定后端 recipe）
- 场景、主体、语言尽量不重复；抽象情绪必须落到画面可见物
